## Descripción del ticket

As a Data team,
we want to understand the Smart Budget use case, define the baseline model logic, and prepare the required dataset and output structure,
so that we can establish a clear foundation for developing and validating the first version of the solution.

---

## Description

This story focuses on building the initial understanding and foundation for the Smart Budget use case.

It includes:

- understanding the business objective and user need;
- defining the baseline logic for budget suggestions (e.g., median-based approach);
- preparing the dataset at the appropriate level of aggregation (user/category/month);
- defining the expected output structure, including suggested values and explanatory metadata.

The goal is not to build the model yet, but to clearly define what will be built in the next sprint.
